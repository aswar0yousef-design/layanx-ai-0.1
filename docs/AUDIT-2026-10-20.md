## 2. ما يعمل فعلًا (مثبت باختبارات)

- عزل المشاريع على مستوى الأدوات والذاكرة والإعادة (اختبارات `project-*-isolation`, `red-team`).
- دورة المهام: تخطيط، تنفيذ عبر Agent Gateway، صلاحيات L1–L5، موافقات، Sentinel، تدقيق، idempotency.
- التعافي: أكثر من 15 ملف اختبار (`recovery-*`) تغطي الاستئناف بعد إعادة التشغيل وحدود الأعطال.
- التخزين المحلي: JSON معاملاتي + SQLite (`node:sqlite`) للمتجهات؛ PostgreSQL محوّل اختياري.
- أدوات الملفات والطرفية (قائمة سماح ضيقة: `git status/diff/log`, `npm test/run typecheck/run build`) وGit.
- MCP Gateway (stdio + Streamable HTTP) بمهلات واختبارات.
- الذاكرة: نصية + دلالية عبر Ollama embeddings عند توفر نموذج تضمين.
- التداول: تحليل، Backtest، Paper؛ التنفيذ الحقيقي (Binance/MT5) مغلق افتراضيًا ويتطلب `BINANCE_LIVE_TRADING_ENABLED=true` + موافقة L4 + حد أقصى للقيمة.
- واجهة Control Center: 24 صفحة، عربي RTL / إنجليزي LTR.

## 3. ما يعمل جزئيًا

- المجدول: كان يدعم (مرة/فاصل/يومي) بتوقيت الخادم فقط، بلا سجل تشغيل دائم ولا إعادة محاولة. **عولج في هذه المرحلة.**
- الطبيب: كان يفحص المزودين فقط. **عولج.**
- Skills Runtime: سجل في الذاكرة فقط؛ الفاحص يتحقق من *وجود* checksum لا من مطابقته للمحتوى؛ لا تثبيت/تحديث من القرص ولا إدارة إصدارات.
- حالات المهمة الفعلية: `planned|running|blocked|verifying|completed|failed|cancelled`؛ لا توجد حالتا `queued` و`waiting_approval` كاسمين (الموافقات تُدار في `ApprovalManager` منفصلًا).
- المتصفح: `browser.read` قراءة HTTP فقط؛ التشغيل التفاعلي عبر Playwright موجود في `autonomy/browser-test.ts` لاختبارات الواجهات فقط.
- فرق الوكلاء: تنفيذ محدود ومتسلسل/محدود التوازي؛ لا قفل ملفات بين الوكلاء.

## 4. واجهة أو محاكاة فقط

- التواصل الاجتماعي: موصل عام (`LAYANX_SOCIAL_PUBLISH_URL`) — ليس تكاملًا أصليًا مع Instagram/TikTok/YouTube (موثّق صراحة في README).
- لا يوجد Mock يُعرض كنجاح في مسار الإنتاج ضمن ما فحصته؛ الـ Mocks موجودة في الاختبارات فقط.

## 5. غير مكتمل / غير منفذ

- توليد الصور والفيديو بنماذج توليد: لا يوجد مزود (لا OpenAI Images ولا Gemini/Imagen ولا ComfyUI). `creator/engine.ts` يجهّز المشاهد ويتحقق من FFmpeg فقط.
- وحدة الشحن واللوجستيات: غير موجودة (يوجد فقط `google-invoice-agent.ts` لاستخراج الفواتير).
- مُثبّت Windows (MSIX/WiX) وسكربت إلغاء التثبيت: غير موجودين؛ يوجد `LayanX.cmd` + `scripts/windows/start.ps1` + `bootstrap.mjs`.
- سكربتات `test:integration` و`test:e2e`: غير موجودة؛ كل الاختبارات تمر عبر `scripts/test-suite-runner.mjs`.
- صفحات واجهة مخصصة لـ: الذاكرة، المهارات، مركز الأمن، التشخيص، النسخ الاحتياطي، استوديو الوسائط، البريد، الشحن. الوضع الفاتح غير موجود (داكن فقط).

## 6. يحتاج API خارجيًا

OpenAI / Anthropic / Gemini، الصوت السحابي (OpenAI audio)، Shopify / WooCommerce REST، Gmail/Google، IMAP/SMTP، Yahoo، Binance، Meta Ads، Agent Reach.

## 7. يحتاج نموذجًا محليًا أو عتادًا

- Ollama + نموذج مثبت (الافتراضي `llama3.2:3b`) — لم يُتحقق من استدلال حقيقي في بيئة التدقيق لعدم وجود Ollama.
- الذاكرة الدلالية: نموذج تضمين مثل `nomic-embed-text`.
- الصوت المحلي: Whisper / Piper / Cohere ASR (سكربتات تثبيت PowerShell).
- التحكم بسطح المكتب: Windows فقط.

جهازك (Ryzen 5 3600، 32GB RAM، GTX 1660 Super 6GB): نماذج حتى ~4.5 GiB (مثل 7B بتكميم Q4) تعمل على GPU بالكامل؛ الأكبر تُقسّم بين GPU/CPU وتصبح أبطأ؛ نماذج 70B غير مناسبة. الطبيب الجديد يحسب هذا تلقائيًا.
